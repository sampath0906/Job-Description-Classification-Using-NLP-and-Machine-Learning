# Job Description Classification Using NLP and Machine Learning

## Project Overview
This project uses Natural Language Processing (NLP) and Machine Learning to automatically classify job descriptions into their respective job categories.

## Technologies Used
- Python
- Pandas and NumPy
- NLTK
- Scikit-learn
- TF-IDF Vectorization
- Gradio
- Pickle

## Project Workflow
1. Data Collection
2. Data Understanding
3. Text Preprocessing
4. Train-Test Split
5. Feature Engineering using TF-IDF
6. Model Building
7. Model Evaluation
8. Model Deployment using Gradio

## Machine Learning Algorithms
- Multinomial Naive Bayes
- Logistic Regression
- Linear Support Vector Classifier (Linear SVM)

## Model Deployment
The trained TF-IDF vectorizer and Linear SVM model are saved using Pickle. A Gradio interface allows users to enter job descriptions and obtain predicted job categories.

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

## Project Objective
To automate job description classification, reduce manual effort, and improve the organization of job-related information.
